# Internationalization Support

## Supported Locales

- `en`: English, the default fallback language.
- `zh`: Simplified Chinese, used for Chinese browser preferences and manual selection.

## Initialization Priority

The app resolves the active language in this order:

1. The user's last selected language saved in `localStorage` under `milestone-pay.locale`.
2. The browser language from `navigator.language`.
3. English (`en`) as the platform default.

Manual language changes are persisted immediately, so refreshes keep the selected language.

## Fallback Policy

All UI copy is read through `src/lib/i18n.ts`. When a translated value is unavailable for the active locale, the app falls back to the English value for that key. The normal application path should therefore avoid blank text and resource-key placeholders in visible UI.

## Current Coverage

The initial coverage focuses on the main role-selection login page and the external contributor portal:

- Login role cards, GitHub connection labels, feature summaries, chips, and OAuth error messages.
- External contributor portal header, language switcher, mode labels, filter chips, KPI labels, empty states, next-action guidance, payout readiness, submission controls, and common feedback messages.

Dynamic task data from the API, repository names, issue numbers, transaction hashes, and user identities are displayed as source data rather than translated resource strings.
